# stroustrup-notes

Notes & experiments from Bjarne Stroustrup’s *Programming: Principles and Practice Using C++* (PPP2).

Source: https://www.stroustrup.com/PPP2.html

Chapters used (C++14, still valid):

- [Chapter 1: Computers, People, and Programming](https://www.stroustrup.com/PPP2e_Ch01.pdf)
- [Chapter 11: Customizing Input and Output](https://www.stroustrup.com/PPP2e_Ch11.pdf)
- [Chapter 22: Ideal and History](https://www.stroustrup.com/PPP2e_Ch22.pdf)
- [Chapter 23: Text Manipulation](https://www.stroustrup.com/PPP2e_Ch23.pdf)
- [Chapter 24: Numerics](https://www.stroustrup.com/PPP2e_Ch24.pdf)
- [Chapter 25: Embedded Systems Programming](https://www.stroustrup.com/PPP2e_Ch25.pdf)
- [Chapter 26: Testing](https://www.stroustrup.com/PPP2e_Ch26.pdf)
- [Chapter 27: The C Programming Language](https://www.stroustrup.com/PPP2e_Ch27.pdf)
- [Glossary](https://www.stroustrup.com/PPP2e_Glossary.pdf)

Code is for learning.
